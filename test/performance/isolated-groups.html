Run npm run compile before opening this file. This benchmark draws at 1920 × 1080 with pixel ratio 2. Each sample includes a one-pixel readback to force rendering. Results are draw times, not frame rates.

Ordinary groups apply opacity to each child. Cached groups use frozen content. These rows show the cost of each rendering mode. All isolated content uses shared paint bounds. The shadow-and-stroke case also exercises the intermediate buffer for perfect drawing. The paragraphs case draws six justified blocks of 640 characters.
